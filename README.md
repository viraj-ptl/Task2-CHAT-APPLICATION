# Task 2 - CHAT APPLICATION 💬

This project is developed for CODTECH Full Stack Development Internship Task 2.

## 📌 Project Description

A Real-Time Chat Application developed using Node.js, Express.js and Socket.IO.
This application allows multiple users to send and receive messages instantly using real-time communication.

---

## 🚀 Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* Socket.IO

---

## ✨ Features

* Real-time messaging
* Multiple user support
* Username feature
* Instant message updates
* Frontend and backend integration
* Simple and attractive user interface

## ▶️ How To Run Project

### Step 1

Install Node.js

### Step 2

Open terminal in project folder

### Step 3

Install required packages

npm install express socket.io

### Step 4

Run server

node server.js

### Step 5

Open browser

http://localhost:3000

---

## 💬 How To Test Chat

1. Open two browser tabs
2. Enter different usernames
3. Send messages
4. Messages appear instantly in both tabs
